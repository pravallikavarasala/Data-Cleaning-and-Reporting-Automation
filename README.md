# Data Cleaning and Reporting Automation

## 📌 Project Overview

This project automates the process of cleaning raw data and generating reports using Python. It demonstrates how to identify and handle missing values, remove duplicate records, standardize inconsistent data, and create automated reports with visual summaries.

---

## 🎯 Objective

The objective of this project is to improve data quality by automating common data preprocessing tasks and generating reports that help in data analysis and decision-making.

---

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- Matplotlib
- OpenPyXL

---

## 📂 Dataset

The dataset contains customer information with the following fields:

- Customer_ID
- Name
- Age
- City
- Purchase_Amount

The dataset intentionally includes:
- Missing values
- Duplicate records
- Inconsistent text formatting

These issues are cleaned during the project.

---

## 🔄 Project Workflow

1. Import required libraries.
2. Load the Excel dataset.
3. Check dataset information.
4. Identify missing values.
5. Fill missing values.
6. Remove duplicate records.
7. Standardize text formatting.
8. Generate summary statistics.
9. Create visual reports.
10. Export the cleaned dataset.
11. Generate an automated summary report.

---
